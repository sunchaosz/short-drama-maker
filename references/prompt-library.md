# 短剧生产提示词库 (Prompt Library)

本文件是 `short-drama-maker` 技能的详细参考。所有阶段模板、质量门清单、提示词配方集中于此，SKILL.md 只做流程调度。复制模板时保留方括号占位符含义，填入具体项目内容。

---

## 0. 创意立项

### 0.1 爆款短剧 7 条核心规则（创意自检表）

1. **前三秒必须抛钩子**：冲突、悬念、反常识，开篇即高潮。
2. **单一强冲突驱动**：一集只讲清一件事，不铺多条支线。
3. **主角有"瘾"与"怕"**：想要的东西明确，阻止他的东西更强。
4. **情绪曲线陡峭**：每 15 秒一个情绪起伏，拒绝平铺。
5. **反转前置**：第一幕就埋反转种子，结尾兑现。
6. **人设高辨识**：口头禅、造型、缺陷，一眼记住。
7. **结尾必留钩**：每集收尾抛新悬念，逼观众追下一集。

### 2.4 分镜模板（6 套，按题材选）

1. **对话驱动**：中近景对切 + 反应镜头，强调表情与口头禅。
2. **动作追逐**：手持跟拍 + 快速剪辑，强调速度感。
3. **情绪独白**：慢推特写 + 浅景深，留白配乐。
4. **反转揭示**：先误导机位，切反打全景揭示真相。
5. **环境铺陈**：全景缓移建立世界观，定调色调。
6. **产品/营销**：2.5D 运镜 + 真实页面捕获 + 节拍同步。

### 2.6 质量门 Q2b 压力测试

- 抽 3 组相邻镜头，比对角色护照字段（发/衣/配饰/年龄）。
- 不一致 → 回退 2.3 重锁护照并重生成该镜头。

## 3. 美术与素材生成（ImageGen 用法）

- **角色定妆**：提示词 = `{{画风锚定}}, 全身/半身/正面, [护照], 纯色背景, 高清, 8k`。每人生成 1–3 张。
- **场景图**：提示词 = `{{画风锚定}}, [场景护照], 建立镜头, 光线{{}}, 电影感`。
- **道具图**：提示词 = `{{画风锚定}}, [道具描述], 产品级打光, 纯背景`。
- 全剧统一负面词：`风格不一致, 多张脸, 变形, 低分辨率`。

---

## 4. 视频生成（VideoGen 用法）

- **图生视频为主**：首帧 = 阶段3定妆/场景图；提示词 = `[护照]+{{动作}}+{{运镜}}+{{光线}}`。
- **文生视频**：仅用于无参考图的环境铺陈镜头。
- **续帧/延长**：单集各镜头生成后，用延长功能补足镜头间过渡，保证连续。
- **多集衔接**：每集末帧构图预留与下集首帧匹配。
